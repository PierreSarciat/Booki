# Booki - Page d'accueil d'une agence de voyage


## Description

Ce projet consiste en l'intégration de la page d'accueil d'une agence de voyage en utilisant HTML et CSS, sans framework ni JavaScript. L'objectif était de créer une interface responsive qui fonctionne sur tous les appareils (mobile, tablette et desktop) à partir des maquettes Figma fournies.
Le projet a été réalisé dans le cadre d’une formation en développement web, en collaboration fictive avec une CTO et un UI designer, selon un cahier des charges précis.

## Fonctionnalités

- Interface responsive adaptée à toutes les tailles d'écran
- Barre de recherche avec filtres interactifs
- Sections "Hébergements" et "Activités" avec cartes dynamiques
- Pied de page complet avec liens utiles
- Design conforme aux maquettes fournies

## Technologie utilisée

- HTML5
- CSS3
- Git & GitHub
